MACRO PRACTICE  (Notepad++)
===========================
A macro RECORDS your keystrokes, then REPLAYS them.
  Macro > Start Recording   (Ctrl+Shift+R)
  Macro > Stop Recording    (Ctrl+Shift+R again)
  Macro > Playback          (Ctrl+Shift+P)         = replay once
  Macro > Run a Macro Multiple Times...            = replay N times, or "until end of file"
  Macro > Save Current Recorded Macro...           = give it a name + shortcut so you can reuse it
Golden rule: record using KEYS (Home, End, arrow keys), not the mouse - mouse clicks aren't recorded.
Finish each recording on the NEXT line, so the replay continues from there.
